# Tournament backend implementation plan

**Goal:** Support event configuration, team competition, manual points, and staff operational data through the existing reducer and API.

**Architecture:** Keep individual people in players and teams in a separate roster. A competitor helper selects the roster used by pairing, standings, cuts, and integrity checks. Preserve match result and account identity fields. Store saved locations by organizer with event snapshots, and record successful commands inside event state.

**Validation:** Add focused feature workflow tests before implementation. Preserve existing tests except obsolete rejection tests for newly supported imports. Run the root typecheck, test, and production build commands using Node 22.
